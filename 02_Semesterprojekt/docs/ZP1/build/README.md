# Folien-Generator

Die ZP1-Folien werden mit pptxgenjs (Node.js) erzeugt, damit sie fuer ZP2 und MEP
weiterverwendet werden koennen. Kein Teil des Python-Programms.

```bash
cd 02_Semesterprojekt/docs/ZP1/build
npm install pptxgenjs
node build_slides.js
```
PDF-Export danach in PowerPoint (Datei -> Speichern unter -> PDF).
